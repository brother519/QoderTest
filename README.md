# 产品说明：益智小游戏集合

## 产品概述

**益智小游戏集合** 是一款基于浏览器的在线休闲游戏中心，无需下载安装，打开网页即可即开即玩。项目集成了 **15 款经典益智与动作小游戏**，涵盖消除、策略、射击、反应等多种类型，适配桌面端键盘与鼠标操作。

## 核心特点

| 特性 | 说明 |
|------|------|
| **即开即玩** | 浏览器直接运行，无需注册或下载 |
| **游戏丰富** | 15 款经典游戏，覆盖益智、动作、策略、休闲四大类型 |
| **难度分级** | 多款游戏支持简单/中等/困难多级难度，适合不同水平玩家 |
| **记录持久化** | 最高分、最佳步数、通关记录自动保存到本地 |
| **视觉体验** | 暗色主题界面、卡片悬停动效、霓虹边框、流畅动画 |
| **统一架构** | 基于 Next.js 14 + TypeScript，代码规范、易于扩展 |

## 技术栈

- **框架**：Next.js 14（App Router）
- **语言**：TypeScript 5
- **样式**：Tailwind CSS 3
- **渲染**：客户端 Canvas / DOM
- **测试**：Jest 30 + Testin
